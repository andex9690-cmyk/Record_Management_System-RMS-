INSTALLATION STEPS
================================================================================

STEP 1: Start XAMPP Services
────────────────────────────
1. Open XAMPP Control Panel
2. Start Apache service
3. Start MySQL service
4. Both should show "Running" status

────────────────────────────

2. Go to: http://localhost/it's rms/setup_database.php

in db.php match your XAMPP setup.

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "Connection failed" when accessing setup_database.php
────────────────────────────────────────────────────────────
Solution:
  1. Verify MySQL is running in XAMPP Control Panel
  2. Check that port 3306 is available
  3. Verify db.php has correct credentials
  4. Try again

ISSUE: Database already exists error during setup
──────────────────────────────────────────────────
Solution:
  This is normal. Database already created. Proceed to login.

ISSUE: Cannot login with demo credentials
──────────────────────────────────────────
Solution:
  1. Run setup_database.php again
  2. Check database was initialized: http://localhost/it's rms/info.php
  3. Verify correct role is selected during login
  4. Clear browser cookies and try again

ISSUE: Contact form not working
───────────────────────────────
Solution:
  1. Check contact_messages table exists: info.php
  2. Verify database connection is working
  3. Check form is using POST method
  4. Review error messages on contact.php

ISSUE: Can't access any pages
─────────────────────────────
Solution:
  1. Verify Apache is running
  2. Check file path: C:\xampp\htdocs\it's rms\
  3. Try accessing: http://localhost/it's rms/index.html
  4. Check browser console for errors (F12)
